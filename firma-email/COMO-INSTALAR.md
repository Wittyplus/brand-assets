# Firma de email Witty+

> Importante: Outlook, Gmail y Apple Mail NO aceptan código HTML pegado como texto. Hay que pegar la firma ya renderizada.

## Outlook (web / nuevo Outlook)
1. Abre `firma-email-vista-previa.html` con doble clic (se abre en el navegador).
2. Pulsa el botón **Copiar firma**.
3. En Outlook: Configuración → Cuenta → Firmas → Agregar firma. Escribe un nombre (ej. "Witty+") y pega con **Cmd+V** en el cuadro grande.
4. El logo se carga desde GitHub (`Wittyplus/brand-assets`). Si no aparece, pon el cursor a la izquierda de tu nombre y usa **Insertar → Imagen** con `witty-firma-logo.png`; luego ajústalo a unos 180 px de ancho.
5. Marca las casillas de predeterminado y pulsa **Guardar**.

## Gmail
Mismo paso de copiar. Abre `firma-email-vista-previa.html`, pulsa **Copiar firma** y pega en Configuración → General → Firma. El logo se carga desde el repo público `Wittyplus/brand-assets`.

## Apple Mail
Ajustes → Firmas → +, desmarca "Usar siempre mi tipo de letra predeterminado" y pega la firma copiada.
